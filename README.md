## 🚀 Cómo contribuir

¡Gracias por tu interés en contribuir a este proyecto!  
Sigue los pasos a continuación para comenzar:

### 1. Haz un Fork del repositorio

Antes de realizar cualquier cambio, crea un **fork** de este repositorio en tu cuenta de GitHub.

### 2. Revisa las categorías pendientes

Ingresa a la página principal del proyecto y revisa las categorías o funcionalidades que aún no han sido implementadas.

> Solo escoge una categoría pendiente para desarrollar, puedes poner un H1 con tu nombre y luego rellenar con lorem ipsum.

### 3. Crea una nueva rama

Una vez realizado el fork, crea una rama para trabajar en tu contribución:

```bash
git checkout -b feature/nombre-de-tu-feature
